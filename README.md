# 🐱 Cat Adventure Calculator

Kalkulator futuristik bertema kucing dengan nuansa game adventure, dibuat menggunakan HTML5, CSS3, dan Vanilla JavaScript.

## Features
- Basic calculator
- Scientific calculator
- Programmer tools
- Unit converter
- Memory MC/MR/M+/M-/MS
- Adventure History dengan LocalStorage
- XP dan level Cat Adventure
- Achievement counter
- Dark/Light Mode
- Sound effect via Web Audio API
- Keyboard support
- Responsive desktop/tablet/mobile
- Tanpa backend dan tanpa framework berat

## Installation
Tidak perlu instalasi. Buka `index.html` di browser.

## GitHub Pages Deployment
1. Upload semua file ke repository GitHub.
2. Buka **Settings**.
3. Pilih **Pages**.
4. Pilih branch `main`.
5. Klik **Save**.

## Keyboard Shortcuts
- `0-9` angka
- `+ - * /` operator
- `Enter` = hasil
- `Escape` = AC
- `Backspace` = hapus
- `.` = desimal
- `%` = persen

## Calculator Modes
- BASIC
- SCIENTIFIC
- PROGRAMMER
- CONVERTER

## LocalStorage
History, memory, XP, level, jumlah perhitungan, tema, suara, dan jumlah desimal tersimpan di browser.

## Customization
- Nama game dan teks dapat diubah di `index.html`.
- Warna tema ada di variabel CSS `:root` pada `style.css`.
- Pesan Cube/Cat Adventure dapat diubah di `script.js`.
- Logo kucing saat ini menggunakan emoji/CSS sehingga tidak membutuhkan gambar eksternal.
